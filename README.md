🌹 The Rose That Grew From Concrete — Interactive Poetry Lesson

An interactive poetry lesson designed to help learners move from literal understanding toward interpretation and central idea.

Audience: Grades 4 - 6
Topic: Literary analysis
Interactions: Knowledge checks, evidence identification, reflection, constructed response
Learning progression: Speaker → Subject → Evidence → Literal Meaning → Symbol → Deeper Meaning → Central Idea
